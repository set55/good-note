> **詳細說明**：16 byte 對齊不是 CPU 硬性要求，而是為了讓**被呼叫的函式**可以放心用 `movaps` 這類需要對齊的指令。被呼叫的函式根本不需要時，對齊就沒有用處。只有 gcc 看得到被呼叫者的本體時才能這樣省；`sum9` 是一般的全域函式，別的檔案呼叫它時，那邊的 gcc 看不到本體，照樣會補齊。完整的程式與輸出見筆記那一小節（範例檔 [`align9.c`](./align9.c)）。

> **批改**：**錯**。抓到一個重點：`h` 對呼叫它的人來說也是被呼叫者，要用 `%rbx` 就得先 `push` 存起原值。但四個值撐過幾次 `call` 錯了三個，所以暫存器數量和對齊也跟著錯：
>
> - `a`：撐過兩次，**對**（最後 `+ a`）。
> - `x`：寫成兩次，**錯**。`x` 是 `g(a)` 的回傳值，`g(a)` 之前它還不存在，只要撐過 `g(b)` 這一次。
