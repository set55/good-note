# small-project 練習索引

這個目錄是[系統化課程](../learning/Linux與系統程式的系統化學習路線.md)的**練習區**：每一課的作業、
每一站的小專案都在這裡自己動手做。它不是筆記——觀念整理在 `c/`、`linux/` 等領域資料夾，
這裡放的是程式碼與實驗紀錄。目前進度見 [學習進度.md](../learning/學習進度.md)。

## 規則

- 每一課一個子資料夾：`s<站>-<兩位數課號>-<英文短名>/`（kernel 段用 `k<站>-...`）。
- 每個子資料夾有一份 `README.md`：作業題目、對應的課程筆記；每題題目下面是自己填的**作答框**，批改寫在作答框正下方，重答再往下接（題目 → 作答 → 批改 → 重答 → 批改）。
- 每個子資料夾有一份 `quiz.md`：本課與延伸筆記的**所有自我測驗**，題目已經放好，直接在空白區塊作答。
- 程式碼自己寫；卡住了就問，但先把錯誤訊息和自己的推測寫進該題的作答框。
- `.gitignore` 是白名單，只有原始碼和 `.md` 會進 git，編譯產物不會。
  想留下某個輸出（例如 `nm`、`strace` 的結果），貼進該題的作答框。
