## 題目

程式碼都在這個資料夾裡**自己寫**（不要複製筆記裡的），每支程式都用 `gcc -Wall -Wextra` 編譯。
每題「解釋原因」的地方都標了答案的來源：
- 【筆記第 X 節】：課堂教過，回筆記那一節找。
- 【新觀念，先猜】：還沒教過，寫下你的猜測就好，猜錯不算錯。

1. **型別大小**：寫 `sizes.c`，印出 `char`、`short`、`int`、`long`、`long long`、`int *`、`char *` 的 `sizeof`，
   以及 `INT_MIN`、`INT_MAX`、`UINT_MAX`。
   - 為什麼 `int *` 和 `char *` 一樣大，雖然它們指向的東西大小不同？【筆記第一、二節】

2. **位元組順序**：寫 `endian.c`，宣告 `int x = 0x0a0b0c0d;`，用 `unsigned char *` 指向 `x`，印出 `*` 讀到的那一個 byte。
   - 從這個 byte 判斷本機是大端序還是小端序，說明你怎麼判斷的。【筆記第三節】
   - 用 `gcc -g -O0` 編譯，在 `gdb` 裡用 `x` 印出 `x` 的全部 4 個 byte，貼上輸出。【筆記第三節】
   - 把 `x` 改成 `short x = 0x0a0b;`，先**預測**第一個 byte 是什麼，再執行驗證。【筆記第三節】

3. **二補數**：寫 `twos.c`，對 `-1`、`-2`、`-128`、`INT_MIN` 各印出 `%d` 和轉成 `(unsigned)` 後的 `%x`。
   - 執行之前，先用「每個 bit 反過來再加 1」手算 `-2` 和 `-128` 的十六進位，把算的過程寫在觀察紀錄，再跟程式輸出對照。【筆記第五節】

4. **停不下來的迴圈**：寫 `loop.c`，用 `for (unsigned int i = 3; i >= 0; i--)` 印出 `i`。
   **在迴圈裡加一個計數器，印 6 次就 `break`**，免得真的停不下來（或準備好用 Ctrl-C 中斷）。
   - 貼上輸出，解釋印到 0 之後為什麼沒有停、接下來那個大數字是怎麼來的。【筆記第四、七節】
   - 分別用 `gcc`（不加選項）、`gcc -Wall`、`gcc -Wall -Wextra` 編譯，哪一種會警告？警告名稱是什麼？【筆記第七節】
   - 把迴圈改成能正確印出 `3 2 1 0` 就停。改法筆記沒有直接寫，用第四、七節講的原因自己想。【筆記第四、七節】

5. **有號溢位**：寫 `ub.c`，照筆記第八節的樣子寫 `bigger()`（分成 `int y = x + 1;` 與 `return y > x;` 兩行），傳入 `INT_MAX`。
   - 用 `-O0`、`-O2`、`-O2 -fwrapv` 各編一次，貼上三個結果，解釋為什麼不一樣。【筆記第八節】
   - 再寫一個無號版本 `unsigned int bigger_u(unsigned int x)`，傳入 `UINT_MAX`。**先預測** `-O2` 下的結果，再驗證。
     為什麼 `-O2` 不能像有號版那樣直接把它變成 1？【筆記第四、八節】
   - 用 `-O0 -fsanitize=undefined` 編譯有號版，貼上 runtime error 那一行。【筆記第八節】
