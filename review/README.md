# 複習作答區

這個資料夾放**間隔複習**的作答與批改，每天一個檔。它不是筆記領域，而是跟 [`small-project/`](../small-project/README.md) 一樣的練習區。
哪一題哪天考，由 [`learning/複習排程.md`](../learning/複習排程.md) 決定：每一題各自一個盒子，每天最多 10 題。

**一句話結論：每天打開當天那一個檔，寫完 10 題以內的關鍵句，跟 Claude 說「幫我批改」。**

---

## 一、怎麼用

1. 開始複習時跟 Claude 說一聲。Claude 會依排程挑出今天的題目，建立 `YYYY-MM-DD-<主題>.md`，並在下面的表格加一列。
2. **闔上筆記**，在每題的作答框裡寫 1～2 句關鍵句就好，不必寫完整段落。
3. 寫完說「幫我批改」。批改和參考答案會寫在每個作答框正下方。複習**不重答**，看完參考答案就結束。
4. Claude 依批改結果移動每一題的盒子，並更新排程表。

- 檔名：`YYYY-MM-DD-<主題>.md`。主題是當天考到的筆記簡稱，用 `-` 連接，例如 `2026-10-01-字元-C資料-objdump-hello-ELF.md`。
