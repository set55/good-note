組語 1-2. 各對應 C 的什麼寫法？

對。a 是 int *、b 是索引時，movl 是 *(a + b)（也就是 a[b]），leaq 是 a + b（也就是 &a[b]）。mov 比 lea 多做的就是那個 *。

【第四節〈lea：只算位址，不碰記憶體〉】

核心關鍵（答到這幾點就算對）：

  1. movl (%rdi,%rsi,4), %eax ↔ a[i]（就是 *(a + i)，a 是 int *）。
