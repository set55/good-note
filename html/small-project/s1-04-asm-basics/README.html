這一課的目標是讀得懂，不是會寫組合語言。每一題都是：自己寫一小段 C → 先預測 gcc 會產生什麼 → 用 gcc -S 實際編出來 → 對照、解釋。

  • 看組合語言一律用：gcc -S -O2 -fno-asynchronous-unwind-tables 檔名.c -o 檔名.s（題目指定 -O0 的除外），然後打開 .s 檔看。不需要 main，因為 -S 不連結。
  • .s 檔不會進 git（白名單），要留的輸出貼進作答框。貼的時候只要函式本體（從 函式名: 到 ret），以 .p2align、.globl 這類 . 開頭的指示詞可以刪掉。
  • 筆記裡的範例可以參考，但每一題的型別、數值、情境都跟範例不同，照抄範例答不出來。

每題「解釋原因」的地方都標了答案的來源：

1. 用 lea 做乘法

寫 mul.c，裡面四個函式（都是 long）：

第 1 次（2026-10-08）

leaq 0x0(,%rdi,$9), %rax

批改：錯。

  • 預測「四個都能一個 lea 做完」不對：從你 1-2 貼的輸出就看得到，只有兩個是一個 lea，另外兩個都是兩個指令。
  • 你寫的 0x0(,%rdi,$5) 有兩個文法問題：① $ 是立即數（immediate）的記號，只用在「整個運算元就是一個數字」的時候（例如 $1）；記憶體運算元括號裡的 D、S 不加 $。② S 不是隨便一個數字都可以。
  • 題目後半「另外幾個為什麼不行」沒有回答。

提示：回筆記第三節 D(B,I,S) 表下面，看 S 只能是哪幾個數。再想：lea 一次能算的是 D + B + I×S，如果 B、I 都放 %rdi（也就是 x），能算出 x 的幾倍？把所有能湊出的倍數列出來，就知道哪幾個做得到、哪幾個做不到。重答時寫出：能一個 lea 做完的那幾行（正確文法），以及其他幾個為什麼不行。
