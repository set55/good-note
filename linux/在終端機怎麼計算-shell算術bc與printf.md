# 在終端機怎麼計算？—— `$(( ))`、`bc`、`printf` 各管什麼，以及它們的陷阱

> 日期：2026-09-24
> 情境：讀 ELF 檔頭時常要換算十六進位（例如進入點 `0x406500` 是十進位多少），問「怎麼用 terminal 計算」
> 適用範圍：本機 Ubuntu 24.04：zsh 5.9（互動 shell）、bash 5.2（`/bin/sh` 也指向它）、GNU bc 1.07.1、GNU coreutils 9.4 的 `expr`；
> OpenWrt 24.10.2 的 BusyBox ash。所有輸出都是實測
> 相關：[錢字號展開的四種形式](./錢字號展開的四種形式-bad-substitution的根因.md)（`$(( ))` 是四種展開之一）、
> [OpenWrt上沒有readelf怎麼觀察ELF檔](../openwrt/OpenWrt上沒有readelf怎麼觀察ELF檔-BusyBox與proc的替代方法.md)

**一句話結論：整數運算、進位換算用 shell 內建的 `$(( ))`（不用開新程式，到處都有，連路由器都能用）；
要小數或超大數字用 `bc`（`-l` 才有小數）；要把數字**印成**十六進位、八進位用 `printf`。
四個陷阱要記住：`$(( ))` 只有整數（zsh 例外）、`^` 是 XOR 不是次方、`010` 在 bash 是八進位、
超過 64 位元會**默默變成負數**。**

---

## 一、先選工具

| 需求 | 用什麼 | 例子 | 結果 |
|---|---|---|---|
| 整數四則、餘數、次方 | `$(( ))` | `echo $(( 7 / 2 ))` | `3`（整數除法，捨去小數） |
| 十六進位 → 十進位 | `$(( ))` 或 `printf '%d'` | `echo $(( 0x406500 ))` | `4220160` |
| 十進位 → 十六進位 | `printf '%x'` | `printf '%x\n' 255` | `ff` |
| 任意進位（2～64） | `$(( base#數字 ))` | `echo $(( 2#1010 ))` | `10` |
| 小數 | `bc -l`、`awk`、zsh 的 `$(( ))` | `echo '7/2' \| bc -l` | `3.50000000000000000000` |
| 超過 64 位元的大數 | `bc`、`python3` | `echo '2^100' \| bc` | `1267650600228229401496703205376` |
| 開根號、三角函數 | `bc -l`、`awk` | `echo 'sqrt(2)' \| bc -l` | `1.41421356237309504880` |

**為什麼優先用 `$(( ))`**：它是 shell **內建**的語法，不用啟動任何程式，所以 bash、zsh、dash、BusyBox ash 都有，
路由器上也能用（第六節）。`bc` 是另外一支程式，OpenWrt 上就沒有。

## 二、`$(( ))`：shell 內建的整數運算

### 文法

```
$(( 運算式 ))        算術展開：算出結果，把整段換成結果的文字
(( 運算式 ))         算術命令：只算、不輸出；結果非 0 時結束狀態為 0（成功），常用在 if／while
```

- `$(( ))` 是**展開**（跟 `$var`、`$(cmd)` 同一類，見 [錢字號展開的四種形式](./錢字號展開的四種形式-bad-substitution的根因.md)），
  所以要放在命令裡才看得到結果：`echo $(( 1 + 2 ))`。只打 `$(( 1 + 2 ))` 會變成執行一個叫 `3` 的命令。
- 裡面的變數可以不加 `$`：`x=5; echo $(( x * 2 ))` → `10`。
- `(( ))` 沒有 `$`，用來改變數或做判斷：`(( x += 2 ))`、`if (( x > 3 )); then ...`。

### 實測（bash 與 zsh 並排）

以下每一行都是用 `bash -c '...'` 與 `zsh -c '...'` 分別執行的結果：

```
                               bash                      zsh
echo $(( 7 / 2 ))              3                         3        ← 整數除法，捨去小數
echo $(( 7 % 2 ))              1                         1        ← 餘數
echo $(( 2 ** 10 ))            1024                      1024     ← 次方是 **
echo $(( 5 ^ 3 ))              6                         6        ← ^ 是 XOR，不是次方！
echo $(( 0x406500 ))           4220160                   4220160  ← 0x 開頭是十六進位
echo $(( 16#ff ))              255                       255      ← base#數字
echo $(( 2#1010 ))             10                        10
echo $(( 010 ))                8                         10       ← 陷阱：bash 當八進位，zsh 當十進位
echo $(( 9223372036854775807 + 1 ))
                               -9223372036854775808      -9223372036854775808   ← 溢位，默默變負數
echo $(( 7 / 2.0 ))            syntax error: invalid     3.5      ← bash 只有整數；zsh 支援小數
                               arithmetic operator
```

### 四個陷阱

1. **只有整數**（bash、dash、ash）：`7 / 2` 是 3，而且 bash 看到 `2.0` 直接報錯：
   `syntax error: invalid arithmetic operator (error token is ".0 ")`。zsh 例外，運算元有小數點就改用浮點數。
2. **`^` 是 XOR（位元互斥或）**，不是次方：`5 ^ 3` 是 `101 XOR 011 = 110`，也就是 6。次方要用 `**`。
   這跟 C 語言一樣（`man bash`：*the same as in the C language*），C 也沒有次方運算子。
3. **開頭是 0 的數字**：bash 依照 C 的規則當成**八進位**，`010` 是 8；zsh 預設當十進位，
   要 `setopt octalzeroes` 才跟 bash 一樣（實測後變成 8）。從檔案讀進來的數字如果帶前導 0（例如日期 `08`），
   在 bash 裡還會報錯，因為 8 不是合法的八進位數字。實測：
   ```
   $ bash -c 'm=08; echo $(( m + 1 ))'
   bash: line 1: 08: value too great for base (error token is "08")
   $ zsh -c 'm=08; echo $(( m + 1 ))'
   9
   ```
4. **溢位不報錯**：數字是 64 位元有號整數，最大 `9223372036854775807`，再加 1 就繞回最小的負數。
   `man bash` 明寫 *no check for overflow*。為什麼是這個數字、為什麼會變負數，正是第 ① 站第 2 課（整數的表示）的主題。
   需要更大的數字就用 `bc`（第三節）。

### 全部運算子（`man bash` 的 ARITHMETIC EVALUATION，依優先順序由高到低）

| 優先順序 | 運算子 | 意思 |
|---|---|---|
| 1 | `id++` `id--` | 後置遞增、遞減（先取值再加減） |
| 2 | `-` `+` | 一元負號、正號 |
| 3 | `++id` `--id` | 前置遞增、遞減（先加減再取值） |
| 4 | `!` `~` | 邏輯 NOT、位元反轉 |
| 5 | `**` | 次方 |
| 6 | `*` `/` `%` | 乘、除（整數）、餘數 |
| 7 | `+` `-` | 加、減 |
| 8 | `<<` `>>` | 位元左移、右移（`1 << 4` 是 16） |
| 9 | `<=` `>=` `<` `>` | 比較，成立是 1、不成立是 0 |
| 10 | `==` `!=` | 相等、不相等 |
| 11 | `&` | 位元 AND（`0xff & 0x0f` 是 15） |
| 12 | `^` | 位元 XOR |
| 13 | `\|` | 位元 OR |
| 14 | `&&` | 邏輯 AND |
| 15 | `\|\|` | 邏輯 OR |
| 16 | `expr ? expr : expr` | 條件運算（跟 C 一樣） |
| 17 | `=` `*=` `/=` `%=` `+=` `-=` `<<=` `>>=` `&=` `^=` `\|=` | 指定 |
| 18 | `expr1 , expr2` | 逗號：兩個都算，結果取後者 |

數字的寫法：`0x` 或 `0X` 開頭是十六進位；bash 裡 `0` 開頭是八進位；`base#n` 可以指定 2～64 進位
（超過 36 進位時，10 以上的數字依序用小寫字母、大寫字母、`@`、`_` 表示）。

### zsh 專屬：直接輸出成其他進位

zsh 的 `$(( ))` 可以在前面加 `[#進位]`，讓**結果**用那個進位印出來（bash 沒有這個功能）：

```
$ echo $(( [#16] 255 ))
16#FF
$ echo $(( [##16] 255 ))       ← 兩個 # 不印出 16# 前綴
FF
$ echo $(( [#2] 10 ))
2#1010
$ zmodload zsh/mathfunc; echo $(( sqrt(2) ))    ← 載入數學函式模組後才有 sqrt 等函式
1.4142135623730951
```

寫腳本時不要用這些，放到 bash 或路由器上就不能跑（道理跟 [GNU是什麼](./GNU是什麼-Linux核心與GNU工具的分工.md) 第四節的 bash 擴充語法一樣）。

## 三、`bc`：小數與任意大的數字

`bc`（basic calculator）是一個小型計算語言，精度沒有上限。

### 用法

```
echo '運算式' | bc [選項]          一次算一個（最常用）
bc [選項]                          互動模式，打 quit 離開
```

```
$ echo '7/2' | bc
3                                  ← 預設 scale=0：小數點後 0 位，一樣只有整數！
$ echo 'scale=4; 7/2' | bc
3.5000                             ← scale 設定小數點後幾位
$ echo '1/3' | bc -l
.33333333333333333333              ← -l 會把 scale 設成 20，並載入數學函式
$ echo '2^100' | bc
1267650600228229401496703205376    ← bc 的 ^ 才是次方，而且沒有 64 位元的上限
$ echo 'sqrt(2)' | bc -l
1.41421356237309504880
```

注意：`bc` 的 `^` 是**次方**，跟 `$(( ))` 的 `^`（XOR）意思完全不同。

### 進位換算：`ibase`、`obase` 的陷阱

`ibase` 是**輸入**用幾進位解讀，`obase` 是**輸出**用幾進位印：

```
$ echo 'obase=16; 255' | bc
FF
$ echo 'ibase=16; FF' | bc               ← 十六進位的數字要用大寫
255
$ echo 'ibase=16; obase=10; FF' | bc
FF                                       ← 陷阱！
$ echo 'obase=10; ibase=16; FF' | bc
255                                      ← 先設 obase 就對了
```

陷阱的原因：`ibase=16` 一設下去，**後面所有數字都用十六進位解讀，包括 `obase=10` 的 10**。
十六進位的 `10` 等於十進位的 16，所以 `obase` 變成 16，結果照樣印出 `FF`。**永遠先設 `obase`，再設 `ibase`**。

### 全部選項（`bc --help` 實測，共 7 個）

| 選項 | 作用 |
|---|---|
| `-h`, `--help` | 印出說明後結束 |
| `-i`, `--interactive` | 強制互動模式 |
| `-l`, `--mathlib` | 載入數學函式庫，並把 `scale` 設成 20 |
| `-q`, `--quiet` | 不印開頭的版本橫幅 |
| `-s`, `--standard` | 使用 POSIX 以外的 bc 語法時報錯 |
| `-w`, `--warn` | 使用 POSIX 以外的 bc 語法時警告 |
| `-v`, `--version` | 印出版本後結束 |

### 特殊變數與函式（`man bc`，全列）

| 名稱 | 意思 |
|---|---|
| `scale` | 小數點後保留幾位，預設 0 |
| `ibase` | 輸入的進位，預設 10 |
| `obase` | 輸出的進位，預設 10 |
| `last` | 上一次的計算結果 |
| `length(x)` | x 的有效位數 |
| `scale(x)` | x 小數點後的位數 |
| `sqrt(x)` | 平方根 |
| `read()` | 從標準輸入讀一個數字 |
| `s(x)` `c(x)` `a(x)` | 正弦、餘弦、反正切（弧度），**要 `-l`** |
| `l(x)` `e(x)` | 自然對數、e 的 x 次方，**要 `-l`** |
| `j(n,x)` | n 階貝索函數，**要 `-l`** |

`bc` 還是一個完整的程式語言（`if`、`while`、`for`、`define` 自訂函式），這部分不列，見 `man bc`。

## 四、`printf`：把數字「印成」某種格式

`$(( ))` 和 `bc` 負責**算**，`printf` 負責**印**，最常用來做進位轉換：

```
$ printf '%d %x %X %o %#x\n' 255 255 255 255 255
255 ff FF 377 0xff
$ printf '%d\n' 0x406500          ← 參數也可以寫成十六進位
4220160
$ printf '%.3f\n' 3.14159
3.142
```

文法：`printf 格式字串 參數...`。格式字串裡每個 `%` 開頭的**轉換說明（conversion specification）**依序吃掉一個參數。
跟數字有關的轉換（這裡只列**數字相關**的這幾個；`%s`、`%b`、`%q` 等字串類與完整清單見 `help printf`（bash）和 `man 3 printf`）：

| 轉換 | 印成 |
|---|---|
| `%d`、`%i` | 十進位整數 |
| `%u` | 無號十進位整數 |
| `%x`、`%X` | 十六進位（小寫、大寫字母） |
| `%o` | 八進位 |
| `%f` | 小數；`%.3f` 表示小數點後 3 位 |
| `%e`、`%E` | 科學記號 |
| `%g`、`%G` | 自動選 `%f` 或 `%e` 裡比較短的 |

`%` 和字母之間可以加修飾：`#`（加上 `0x`、`0` 前綴）、寬度（`%8x`）、`0` 補零（`%08x` → `000000ff`）。

## 五、其他方式

| 工具 | 例子 | 特點 |
|---|---|---|
| `awk` | `awk 'BEGIN{print 7/2, 2^10, sqrt(2)}'` → `3.5 1024 1.41421` | 預設就是浮點數，`^` 是次方；路由器上也有（BusyBox） |
| `python3` | `python3 -c 'print(7/2, 7//2, hex(255), 2**100)'` → `3.5 3 0xff 1267650600228229401496703205376` | 最直觀、整數沒有上限；但要啟動直譯器，比較慢 |
| `expr` | `expr 7 / 2` → `3` | 最古老的方式，每個運算子都要是獨立參數，而且容易踩坑（見下面） |

**`expr` 的陷阱**：`*` 會先被 shell 當成萬用字元展開成目前目錄的檔名。實測在 `/tmp` 執行：

```
$ expr 3 \* 4
12
$ expr 3 * 4
expr: syntax error: unexpected argument 'claude-1000'     ← * 被展開成 /tmp 底下的檔名
```

`expr` 是 `$(( ))` 出現之前的舊方法，新寫的腳本沒有理由用它。它的全部運算子（`expr --help`，依優先順序由低到高）：
`|`、`&`（邏輯）；`<` `<=` `=` `!=` `>=` `>`（比較）；`+` `-`；`*` `/` `%`；
`STRING : REGEXP` 與 `match`（正規表示式比對）、`substr`、`index`、`length`（字串操作）；`+ TOKEN`（強制當字串）；`( )`（分組）。

## 六、路由器（OpenWrt）上能用什麼

```
root@OpenWrt:~# echo "7/2=$(( 7 / 2 )) 010=$(( 010 )) 0xff=$(( 0xff )) 2**10=$(( 2 ** 10 ))"
7/2=3 010=8 0xff=255 2**10=1024           ← ash 跟 bash 一樣：010 是八進位
root@OpenWrt:~# echo $(( 7 / 2.0 ))
ash: arithmetic syntax error              ← 只有整數
root@OpenWrt:~# awk 'BEGIN{print 7/2, sqrt(2)}'
3.5 1.41421                               ← 要小數就用 awk
root@OpenWrt:~# printf '%x\n' 255
ff
```

`bc`、`dc` 都**沒有**；`expr` 有。所以在路由器上：整數與進位換算用 `$(( ))` 和 `printf`，小數用 `awk`。
